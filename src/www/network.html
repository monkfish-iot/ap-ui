仅支持同网段 IP，避免彻底失联
留空则使用上游 DHCP 下发的 DNS
DHCP 模式下，IP 地址、掩码、网关、DNS 都由上游 DHCP 服务器自动分配。
安全说明
  • 修改静态 IP 时，新 IP 必须与当前 IP 处于同一子网，否则后端会拒绝写入。
  • 设置生效后 60 秒内未点击「保留修改」，系统会自动回滚到上一版配置。
  • 切换 DHCP → 静态 时，如果新 IP 与网关不在同一网段，设备将无法上网。
